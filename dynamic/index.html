Dynamic Typography 2024

A new application of variable font features to transform style rather than weight.

A demonstration of how variable fonts transition between weights, widths and serifs. Everything is contained in a .ttf font file, meaning motion graphics are much easier to create and multiple styles can be conveyed using the same font family without compomising a wider visual identity: Everything remains cohesive as everything is a variation of the original font.

Visualisation of how an a-z transitions between styles.

Exploration into how a single font can have both angular and smooth variations, including the options in between the two.

Experimenting how corner elements, conventionally used to apply serifs, can be used to change letter shapes dynamically: Both by adding and removing positive space.

Looking into how ink traps can change the appearance of a font without affecing the core structure of the letters.
