# Papa's Park Website

A modern, responsive website for Papa's Park, a community playground in Brixton, London.

## Description

This website serves as an online presence for the Pulross Area Play Association (PAPA), a community organization that manages Papa's Park. The site showcases the park's facilities, history, and provides information for visitors.

## Features

- Responsive design that works on mobile, tablet, and desktop devices
- Modern, clean layout with accessibility considerations
- Contact form for visitor inquiries
- Newsletter signup for community updates
- Interactive Google Map for location information
- Mobile-friendly navigation
- Donation section to support the park

## Technologies Used

- HTML5
- CSS3 (with Flexbox for layouts)
- JavaScript (ES6+)
- Google Fonts
- Font Awesome icons
- Google Maps integration

## Setup

1. Clone this repository
2. Open `index.html` in your browser to view the site

## Structure

- `index.html` - Main HTML file
- `style.css` - All styles for the website
- `script.js` - JavaScript functionality
- `images/` - Directory containing all website images
