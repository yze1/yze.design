# Images Directory

This directory should contain the following images for the Papa's Park website:

## Required Images:
1. `papas-park-logo.png` - The logo of Papa's Park
2. `papas-park-hero.jpg` - Hero/banner image for the homepage
3. `papas-park-community.jpg` - Image showing community members at the park
4. `papas-park-building.jpg` - Image of the park building for the donation section
5. `mailchimp-logo.png` - Mailchimp logo for the newsletter section

## Favicon Requirements:
6. `favicon-16x16.png` - 16x16 favicon
7. `favicon-32x32.png` - 32x32 favicon
8. `apple-touch-icon.png` - 180x180 Apple touch icon

## Image Specifications:
- Logo: Transparent background, PNG format, approximately 150px width
- Hero image: High-quality, landscape orientation, minimum 1920px width
- Community and building images: High-quality, square or landscape, minimum 800px width
- Mailchimp logo: Small, approximately 100px width
- Favicons: Standard web icon formats

## Sourcing Images:
If actual images are not available, you can:
1. Take photographs of the actual location
2. Use appropriate stock photos (with proper licensing)
3. Create/commission custom graphics

## Important Note:
Please ensure you have proper rights to use any images placed in this directory.

## Temporary Solution:
Until actual images are available, the website layout will display properly, but image areas will appear blank or show "broken image" placeholders. This won't affect the functionality of the site.
